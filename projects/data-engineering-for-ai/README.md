# Data Engineering Applied to AI

## Overview

This project explores the fundamentals of data engineering and their applications in AI systems. Developed as part of the GenAI, Data & Cybersecurity bootcamp, it uses NotebookLM as a research and learning environment to organize technical sources, connect concepts, and support practical exploration.

## Objectives

- Understand core data engineering concepts, architectures, and practices.
- Explore data ingestion, transformation, storage, orchestration, and data quality.
- Investigate how data pipelines support AI and machine learning workflows.
- Connect theoretical concepts with practical examples and technical implementations.
- Develop a structured knowledge base grounded in reliable technical sources.

## Scope

The study focuses on the following topics:

- Data Engineering Fundamentals
- ETL and ELT Pipelines
- Data Warehousing, Data Lakes, and Lakehouse Architectures
- Data Processing and Orchestration
- Data Quality, Testing, and Governance
- Data Pipelines for AI and Machine Learning Systems

## Methodology

The project follows an iterative research and learning process:

1. Collect technical sources, including documentation, courses, videos, articles, and books.
2. Use NotebookLM to explore concepts, summarize sources, and identify relationships between topics.
3. Review and compare information across sources, prioritizing reliable and technically grounded references.
4. Document key concepts, examples, limitations, and open questions.
5. Develop practical experiments to apply the concepts studied.

AI-generated summaries and explanations are treated as research aids and are checked against the original sources whenever possible.
