# Research Sources

## Purpose

This document catalogs the technical sources selected for the **Data Engineering Applied to AI** project. The sources support the study of data engineering foundations, workflow orchestration, data management, and the infrastructure and practices used in machine learning systems.

## Source Selection Criteria

Sources are evaluated based on:

- **Authority:** Official documentation, established educational programs, or recognized technical practitioners.
- **Relevance:** Connection to data engineering, data pipelines, data management, or ML infrastructure.
- **Technical depth:** Explanations, practical examples, or architectural discussions.
- **Currency:** Publication date and compatibility with current tools and practices.
- **Traceability:** Availability of links and verifiable technical information.

## Research Notes

- Distinguish course material, technical tutorials, and official documentation.
- Record publication dates or tool versions when relevant.
- Verify important technical claims against primary sources whenever possible.
- Avoid treating historical course editions as current implementation guidance.
- Update each source's status as it is reviewed.

## Source Status Definitions

- **Selected for review:** Included in the research base but not yet fully reviewed.
- **In review:** Currently being examined.
- **Reviewed:** Examined for relevance and technical content.
- **Pending verification:** Metadata or technical scope needs confirmation.
- **Not used:** Retained in the catalog for traceability but not used in the research conclusions.
