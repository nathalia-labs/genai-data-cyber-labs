# Research Sources

## Purpose

This document catalogs the technical sources used in the Data Engineering Applied to AI project. Sources are selected to support conceptual understanding, technical investigation, and practical experimentation.

## Source Selection Criteria

Sources are evaluated based on:

- **Authority:** Official documentation, recognized technical educators, academic publications, or experienced practitioners.
- **Relevance:** Direct connection to data engineering concepts and practices.
- **Technical depth:** Clear explanations, implementation examples, or architectural discussions.
- **Currency:** Publication date and compatibility with current tool versions.
- **Traceability:** Availability of references, examples, and verifiable technical information.

## Sources

### S001 — Data Engineering Zoomcamp

- **Provider:** DataTalksClub
- **Type:** Free online course
- **Link:** https://github.com/DataTalksClub/data-engineering-zoomcamp
- **Topics:** Data ingestion, orchestration, data processing, storage, and data pipelines.
- **Relevance:** Provides a practical and structured introduction to modern data engineering.
- **Limitations:** Tool versions and implementation details may vary across course editions.
- **Status:** To be reviewed

### S002 — Apache Airflow Documentation

- **Provider:** Apache Software Foundation
- **Type:** Official technical documentation
- **Link:** https://airflow.apache.org/docs/apache-airflow/stable/core-concepts/index.html
- **Topics:** DAGs, tasks, dependencies, scheduling, and workflow orchestration.
- **Relevance:** Serves as a primary reference for understanding pipeline orchestration.
- **Limitations:** Focuses on Airflow and does not represent every orchestration approach.
- **Status:** To be reviewed
